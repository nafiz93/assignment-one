
# TypeScript Assignment 1

This repository contains my solutions to **8 TypeScript problems** and **2 short TypeScript blog posts**. I created this project to practice TypeScript basics, reusable functions, generics, object-oriented programming (OOP), and asynchronous code.

## Technologies Used

- **TypeScript** — to write code with types.
- **Node.js** — to run the compiled JavaScript.
- **npm** — to install project dependencies.

## Project Structure

```text
assignment one/
├── src/
│   └── solution.ts             # All 8 TypeScript solutions
├── dist/
│   └── solution.js             # JavaScript generated by TypeScript
├── generics-and-promise.md    # Blog about generics and Promise<T>
├── type-vs-interface.md       # Blog about type and interface
├── package.json               # Project information and dependencies
├── package-lock.json          # Dependency lock file
├── tsconfig.json              # TypeScript compiler settings
└── README.md                  # Project documentation (this file)
```

> **Note:** The `node_modules/` folder is created after installing dependencies. It is usually not uploaded to GitHub. The `dist/` folder contains generated code and may also be ignored in Git.

## Problem Solutions

All solutions are written in `src/solution.ts`.

| Problem | Topic | What I Practiced |
|---|---|---|
| 1 | Default parameters | Multiply a number using a default multiplier of `2`. |
| 2 | Union types and type narrowing | Handle strings, numbers, and booleans differently. |
| 3 | Readonly tuples | Format a location using latitude, longitude, and a name. |
| 4 | Generics and rest parameters | Combine multiple arrays into one. |
| 5 | Interfaces and filtering | Find published courses with enough students. |
| 6 | `keyof` and generics | Collect values for a selected object property. |
| 7 | Classes and inheritance | Use `Employee`, `Manager`, `private`, `protected`, and `super`. |
| 8 | Promises and `async/await` | Validate age using `resolve`, `reject`, and `try/catch`. |

## How to Run the Project

**Step 1: Install dependencies**

Open the terminal inside the project folder.

```bash
npm install
```

**Step 2: Compile TypeScript**

```bash
npx tsc
```

This compiles TypeScript into JavaScript using `tsconfig.json`.

**Step 3: Run the JavaScript**

```bash
node dist/solution.js
```

### Example Console Output

```text
50
typescript
Inactive
[ 'a', 'b', 'c', 'd' ]

```

The last message appears after about one second because Problem 8 uses `setTimeout()`.

Some functions return values without printing them, so they will not appear in the terminal unless we use `console.log()`.
